Java Applet Not Supported

Your browser does not support Java applets. This is normal for modern browsers.

⚠️ Note: Java applets are deprecated and no longer supported in modern web browsers for security reasons.

To play Scorched Earth locally, you have options:

Option 1: Desktop Client

Build and run the desktop version from the Scorched Earth repository:

gradle scorchDesktopClientJar

Then run: java -jar build/ScorchDesktopClient.jar

Option 2: Modern Web Port

A modern web-based version would require converting the game to JavaScript/Canvas (WebGL). This is a significant undertaking.
